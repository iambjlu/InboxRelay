# InboxRelay

把 Telegram「投遞箱」群組裡丟的東西（文字、照片、連結、檔案）自動搬到 Discord，
再用你自己的 AI 模型幫忙整理：摘要、關鍵字、圖中文字、每日／月／年總結、自然語言搜尋，還有一個像 ChatGPT 的對話頻道。

全部在你自己的 Mac 上執行：AI 走你指定的 OpenAI 相容端點（例如 oMLX），圖片文字辨識用 Mac 內建的 Apple Neural Engine。

---

## 它會幫你做什麼

| 功能 | 說明 |
|---|---|
| 📥 搬移 | Telegram 投遞箱的新訊息 → Discord #投遞箱鏡像（相簿合併、超過上傳上限的檔案只貼檔名） |
| 🔁 同步 | Telegram 上編輯或刪除 → Discord 跟著改；在 Discord 鏡像頻道直接發文 → 也發到 Telegram |
| 🔗 連結摘要 | 網頁條列重點；讀不到正文時改用網頁預覽＋截圖；連到圖片的網址做圖片摘要＋文字辨識 |
| 🖼️ 圖片／📄 檔案 | 圖片摘要、PDF／Office／純文字／程式碼檔案總結（只讀不執行） |
| 🔤 圖中文字 | 用 Mac 的 Neural Engine 辨識圖片裡的字，搜尋與總結都會用到（信用卡號只留末四碼） |
| 🏷️ 關鍵字 | 每則訊息抽關鍵字與一句話重點 |
| 🧾 總結 | 每日、每月、每年總結，依日期順序發到 #總結 |
| 🔍 搜尋 | 在 #搜尋 用一般的話問，例如「9/30 吃了什麼」，回答附出處 |
| 💬 AI 對話 | 在 AI 對話頻道發訊息就開一個對話串，可以傳圖片、文件、連結 |
| 🧠 記憶 | AI 會整理你的用語、偏好（你可以直接在 Discord 改） |
| 📒 補充資料 | 匯入財政部電子發票 CSV、通用 JSONL，一起進總結與搜尋 |

## 需要準備

- macOS 14 以上的 Mac（建議 Apple Silicon）
- Xcode 命令列工具：`xcode-select --install`
- Python 3.9 以上
- 一個 Telegram Bot（加進你的投遞箱群組，並關掉 Privacy Mode）
- 一個 Discord Bot（開啟 **Message Content Intent**），邀請到你的伺服器
- 一個 OpenAI 相容的 LLM 端點（例如 oMLX）；要做圖片摘要，模型需支援看圖

### Discord 頻道

| 頻道 | 必要 | 用途 |
|---|---|---|
| #投遞箱鏡像 | ✅ | 搬過來的訊息與 AI 摘要回覆 |
| #關鍵字庫 | ✅ | 每則訊息一筆紀錄（程式的資料庫，不用看） |
| #資料庫 | ✅ | 狀態、#記憶、#提示詞 |
| #總結 | ✅ | 每日／月／年總結 |
| #搜尋 | ✅ | 自然語言搜尋 |
| 通知與互動 | 建議 | 記憶升級通知；用一般的話要求修改總結 |
| 連結預覽與進度 | 選用 | 網頁截圖、背景工作進度 |
| 補充資料 | 選用 | 發票、筆記等匯入資料 |
| AI 對話 | 選用 | 像 ChatGPT 的對話（每個對話一個對話串） |
| AI 對話提示詞與記憶 | 選用 | AI 對話用的 #提示詞 與 #記憶 |

Bot 需要的權限：檢視頻道、發送訊息、附加檔案、嵌入連結、讀取訊息紀錄、管理訊息；
AI 對話頻道另外需要「建立公開討論串」「在討論串中傳送訊息」「新增反應」。

## 安裝

```bash
cd InboxRelay
./install_app.sh
```

會編譯選單列 App、放到「應用程式」並打開。第一次啟動會在背景建立 Python 環境（約 1～3 分鐘）。

打開選單列圖示 →「設定」，填好 Token、群組 ID、頻道 ID、LLM 端點與模型名稱 → 儲存，核心會自動重新啟動。

> Token 存在 macOS 鑰匙圈。也可以選一個同步資料夾（例如 iCloud Drive）存 `settings.json`，
> 讓多台 Mac 共用設定；打開「Token 也存到資料夾」時 Token 會以明碼寫進那個檔案，請自行評估。

更新程式碼後再跑一次 `./install_app.sh` 就好。

## 選單列 App

- **外部 LLM 工作**、**本機 ANE 文字辨識** 兩條「車道」，各自可以：
  - 立即執行、暫停／繼續
  - 排程模式：永遠立即執行／每天自動開始到做完為止／每天自動開始與暫停／手動執行
- 狀態顏色：🟢 執行中、🔵 等待時段、🟠 已暫停、🔴 LLM 離線（工作都留著，下次開始時間自動重試）
- 主視窗：儀表板、設定、日誌（日誌只在記憶體，不寫檔）
- 設定底部的「重設」可以清除 Discord 上的資料重新來過（會再確認一次）

AI 對話、搜尋、通知頻道的互動不受排程限制，隨時可用。

## 日常使用

### 搜尋
在 #搜尋 直接問：「上禮拜去哪裡吃飯」「發票最貴的是哪一筆」。對 bot 的回答按「回覆」可以追問。

### AI 對話
- 在 AI 對話頻道發訊息 → bot 開一個對話串回覆，之後在串裡繼續聊。
- 訊息開頭加 `/思考`：讓模型先思考（較準、較慢）。
- 在對話串裡發 `/compact`：手動壓縮對話（用到設定的門檻也會自動壓縮，壓縮時有進度條）。
- 每則回覆最下面的小字是目前上下文用量。
- 說「記住…」「以後…」，AI 會整理進記憶。

### 修改總結
在通知頻道用一般的話說，例如「9/30 的每日總結漏了晚餐，要補上」、「以後總結都把吃的東西列出來」。

### 改提示詞與記憶
在 #資料庫（AI 對話則在它的提示詞頻道）發一則以 `#提示詞 名稱` 或 `#記憶` 開頭的新訊息就會蓋掉舊版；舊版都留在頻道裡。

## 匯入

終端機指令（詳見 [使用說明.md](使用說明.md)）：

```bash
./run.sh import --path <Telegram Desktop 匯出資料夾> --dry-run   # 先試跑
./run.sh import --path <Telegram Desktop 匯出資料夾>
./run.sh import-extra --path <發票 CSV 或 JSONL 資料夾>
```

匯入歷史訊息時要先結束 App；`import-extra` 可以和 App 同時跑。

## 隱私與硬碟

- 圖片、檔案、網頁、截圖都只在記憶體處理，用完就釋放，不落地。
- 所有資料存在你的 Discord 伺服器；本機只放 Python 環境與少量檔案於
  `~/Library/Application Support/InboxRelay`。
- 只有「失敗」才寫紀錄檔：`ocr-failures.log`（圖片文字辨識）、`linkshot-last.log`（網頁截圖）。
- 網頁截圖使用不保存 Cookie／快取的瀏覽器設定。

## 疑難排解

| 狀況 | 看哪裡 |
|---|---|
| App 編譯失敗 | `app/.build.log` |
| 網頁截圖失敗 | `~/Library/Application Support/InboxRelay/linkshot-last.log` |
| 圖片顯示「（無法取得圖片）」 | `~/Library/Application Support/InboxRelay/ocr-failures.log` |
| 外部 LLM 顯示離線 | 確認端點與模型名稱；恢復後按「立即執行」或等下次開始時間 |
| 頻道權限錯誤 | 主視窗日誌會列出缺哪個權限 |
